## Project Context
MirrorWalk is a run/walk-tracking prototype that combines activity tracking with an augmented-reality experience. Its core concept is to let users view a visual “ghost” of a previous best run through the camera, creating a way to compare a current effort with a past performance. The project uses native Android development, with ARCore as the required technology for the AR experience.
