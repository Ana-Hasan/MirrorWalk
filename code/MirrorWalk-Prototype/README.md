# MirrorWalk

Feature 1 prototype: GPS run recording, a live OpenStreetMap-based map, live distance/pace, and Room persistence of every captured location point.

## Maps

Maps use MapLibre with OpenFreeMap's public OpenStreetMap style. No API key or billing account is required; the device needs an internet connection to load map tiles.

## Run

Open this folder in Android Studio, let Gradle sync, choose an emulator image that includes Google Play, and run the `app` configuration.
